# 贪吃蛇游戏

一个基于 HTML5 Canvas 的经典贪吃蛇游戏，纯前端实现，浏览器直接打开即可游玩。

## 在线游玩

👉 [点击这里在线玩](https://lai0047.github.io/html5-snake/)

## 运行方法

直接在浏览器中打开 `index.html` 文件即可，无需安装任何依赖。

## 功能特性

- **计分板**：实时显示当前分数和历史最高分
- **音效系统**：吃食物、游戏结束、暂停均有音效反馈
- **玩家排行榜**：记录前 10 名玩家的成绩（存储在浏览器本地）
- **暂停功能**：按 P 键随时暂停/继续游戏
- **难度递增**：每吃 5 个食物游戏速度自动加快
- **全中文界面**

## 操作说明

| 按键 | 功能 |
|------|------|
| 方向键 / WASD / HJKL | 控制蛇的移动方向 |
| P | 暂停 / 继续游戏 |
| 空格 / 回车 | 游戏结束后重新开始 |

## 游戏规则

- 控制蛇吃掉食物来增长身体
- 每吃 5 个食物，游戏速度会加快
- 蛇撞到墙壁或自身则游戏结束
- 游戏结束后输入名字，成绩将记录在排行榜中
- 按空格键或回车键可重新开始

## 改进内容

基于原项目 [JDStraughan/html5-snake](https://github.com/JDStraughan/html5-snake) 进行了以下改进：

- 新增 **暂停功能**：按 P 键可暂停/继续游戏
- 新增 **计分板**：实时显示当前分数和最高分
- 新增 **音效系统**：使用 Web Audio API 实现吃食物、游戏结束、暂停音效
- 新增 **玩家排行榜**：基于 localStorage 存储前 10 名成绩
- 界面全面中文化
- 重新设计 UI 为深色主题
